# 🚀 Quick Installation Guide

## Step 1: Load the Extension

1. Open **Google Chrome**
2. Type `chrome://extensions/` in the address bar and press Enter
3. Enable **Developer mode** using the toggle in the top-right corner
4. Click the **"Load unpacked"** button
5. Navigate to and select the `chrome-reader-extension` folder
6. The extension should now appear in your extensions list!

## Step 2: Pin the Extension (Optional but Recommended)

1. Click the puzzle piece icon (🧩) in the Chrome toolbar
2. Find "SerenityReader" in the list
3. Click the pin icon (📌) next to it
4. The extension icon will now be visible in your toolbar

## Step 3: Try It Out!

1. Navigate to any article or blog post (try a news site)
2. Click the SerenityReader extension icon
3. Click "Enable Reader View" or "Remove Ads"
4. Enjoy distraction-free reading!

## Step 4: Customize (Optional)

1. Click the extension icon
2. Click "Settings"
3. Adjust:
   - Font size
   - Font family
   - Line height
   - Content width
   - Color theme (Light/Dark/Sepia)
4. Click "Save Settings"

## Troubleshooting

**Extension not showing up?**
- Make sure you selected the correct folder
- Check that all files are present (manifest.json, etc.)

**Reader view not working?**
- Make sure you're on a regular webpage (not chrome:// pages)
- Try refreshing the page
- Some sites with complex layouts may not work perfectly

**Settings not saving?**
- Open the Settings page
- Make your changes
- Click the "Save Settings" button

## Uninstall

1. Go to `chrome://extensions/`
2. Find "SerenityReader"
3. Click "Remove"
